 10. Canonical Data Model Rules 
Use one canonical model per business concept. 
Do not recreate legacy overlap. 
Required rules: 
1. Use one canonical Order model. 
2. Use OrderItem for commercial line items. 
3. Use JobTicket for production execution. 
4. Use one canonical Task model with typed links/sources. 
5. Use one canonical Notes/Comments model with typed links. 
6. Use one canonical Notiﬁcation model. 
7. Use one canonical Activity/Audit event system. 
8. Store money as integer cents. 
9. Store quantities with explicit units. 
10. Use deterministic services for pricing, inventory, payroll, taxes, and money. 
11. Do not let the frontend calculate authoritative money, inventory, payroll, or tax values. 
12. AI cannot directly mutate money, inventory, approvals, refunds, purchase orders, or selling prices.
